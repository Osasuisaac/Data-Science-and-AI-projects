# 📊 Data Science and AI Projects

This repository contains a collection of my assignments, hands-on projects and dissertation from the **MSc Artificial Intelligence and Data Science** programme at the **University of Hull**, showcasing skills in data cleaning, analysis, visualisation, machine learning and deep learning using Python.

---

## 📁 Contents

### 1. 📌 Census Project: Cleaning and Analysis
- Explores demographic and socio-economic data
- Focuses on trends and patterns across selected regions
- Techniques used: Data cleaning, EDA, hypothesis testing, visualisation
- Tools: `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`
- 📂 [View notebook](Census%20project%20cleaning%20and%20Analysis.ipynb)

### 2. 🚗 CNN Model for Classifying Car Images
- Built a Convolutional Neural Network to classify images of cars
- Applied image preprocessing and augmentation techniques
- Tools: `TensorFlow`, `Keras`, `Matplotlib`
- 📂 [View notebook](CNN%20MODEL%20FOR%20CLASSIFYING%20CAR%20IMAGES.ipynb)

### 3. 🎥 Predicting Customer Spending Behaviour in Streaming Services
- Analysed key drivers behind customer spending patterns
- Developed predictive models using supervised machine learning
- Tools: `Scikit-learn`, `Pandas`, `Seaborn`
- 📂 [View notebook](Predicting%20Customer%20Spending%20Behaviour%20in%20Streaming%20Services%20.ipynb)

### 4. ⚽ MSc Dissertation: Predicting Transfer Market Value in Football
- Predicts the transfer value of European footballers using Football Manager 2024 data
- Compared Random Forest, Gradient Boosting and XGBoost; XGBoost performed best (R² 0.868)
- Engineered features including league strength from UEFA coefficients, with SHAP for explainability
- Tools: `Pandas`, `Scikit-learn`, `XGBoost`, `SHAP`, `Matplotlib`
- 📂 [View project](MSc-Dissertation-FM24-Player-Valuation/)
